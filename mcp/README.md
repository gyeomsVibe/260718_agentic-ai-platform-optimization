# MCP 섹션 — AI에 외부 기능을 연결하는 서버 모음

> 세 플랫폼(Claude Code · Codex · Antigravity)에 붙이는 **MCP 서버**들을 관리하는 섹션입니다.
> 개별 MCP는 최상위에 두지 않고 **여기 아래 하위 폴더**로 넣습니다.

## MCP가 뭔가요? (비유로 이해하기)

**MCP(Model Context Protocol)** 는 AI 도구와 외부 프로그램을 잇는 **표준 연결 단자**입니다.
USB 단자를 떠올리면 됩니다 — 한 번 표준을 정해 두면, 어떤 AI 도구든 같은 방식으로
외부 기능(자료 검색, 파일 조작, 외부 서비스 호출 등)을 꽂아 쓸 수 있습니다.

- **MCP 서버** = 그 단자에 꽂는 어댑터 프로그램. 하나가 하나의 외부 기능을 담당합니다.
- 이 저장소에서 다루는 세 AI 도구는 모두 MCP 단자를 지원하므로, MCP 서버 하나를 만들면
  **세 도구가 공유**할 수 있습니다. 그래서 특정 도구 폴더가 아니라 공용 `mcp/` 섹션에 둡니다.

## 이 섹션의 규칙

- **개별 MCP = 하위 폴더 하나.** 새 MCP를 추가하면 `mcp/<이름>/` 폴더를 만들고, 그 안에
  가이드·설계·캐시를 모읍니다. 날짜가 붙은 개별 MCP 폴더를 저장소 최상위에 두지 않습니다.
- **폴더 안에 진입점 README를 둡니다.** 처음 보는 사람이 "이 MCP가 뭐고 어떻게 연결하나"를
  바로 알 수 있게 합니다.
- **비밀정보 금지.** 쿠키·토큰·세션 파일은 커밋하지 않습니다 (로컬에만 보관).
