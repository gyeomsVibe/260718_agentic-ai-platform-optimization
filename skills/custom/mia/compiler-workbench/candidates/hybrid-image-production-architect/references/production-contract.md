# Image Production Contract

Use this reference only after selecting an image-production route. It does not
override active safety, tool, or workspace instructions.

## Route rules

| Route | Required focus | Completion boundary |
|---|---|---|
| Identity-preserving | Authorized visible-structure anchors; headshot/chest-up → 3/4 → stable full body | Stop when identity drift remains unresolved. |
| Failure diagnosis | Up to three supported causes and the broken constraint | Return one narrowed retry package. |
| Sticker or emoticon | Distinct actions, readable short Korean text, safe margins, controlled background, coherent set logic | Do not claim text legibility without a rendered result. |
| Panel comic | Panel script, character continuity, readable Korean dialogue, safe speech-bubble layout, rewarding final panel | Keep a panel plan separate from image execution. |
| Advertising shot | Product prominence, focal hierarchy, natural pose, low clutter | Do not make performance or CTR claims without evidence. |
| Music-video stills | Text-free scene translation and consistent atmosphere across shots | Preserve sequence continuity. |
| Reverse prompt | Lighting, palette, lens, angle, subject treatment, atmosphere, reusable constraints | Report visible evidence, not hidden prompt recovery. |
| Turnaround | Front, back, left, right, strict overhead orthographic top | Exactly five views; no ambiguous top view. |
| Aspect-ratio variant | Keep the subject and focal hierarchy while reframing for the requested ratio | State crops or content changes required. |
| Packaging | Organize already-approved instructions and assets | File creation, archive creation, or export needs separate approval. |

## Visible-structure safety

For an authorized likeness-sensitive request, use only visible and relevant
anchors such as face outline, brow shape, eye geometry, nose profile, lip
contour, jawline, visible asymmetry, distinctive visible marks, hairline, and
silhouette. Do not infer identity, personality, morality, health, ethnicity,
or any other sensitive attribute. Treat older or heavily transformed photos as
style or supporting references rather than equal identity anchors.

## Prompt construction

Translate the brief into an instruction with these ordered parts:

1. Subject and identity anchors when authorized.
2. Pose or action and framing.
3. Apparel, object, product, or surface details.
4. Environment, composition, lighting, and palette.
5. Text, legibility, aspect-ratio, and delivery constraints.
6. Negative or restriction notes only when they prevent a concrete risk.

Use measurable replacements for vague terms. For example, turn “natural pose”
into relaxed hands and shoulders, no forced twist, stable gaze, and a visible
product; turn “cute” into specified proportions, expression, blush, and detail
density. Preserve the user’s intent while making the constraints executable.

## Failure recovery

When an output drifts, averages the face, contradicts constraints, or lacks
needed information:

1. Stop broadening the request.
2. Name the supported failure cause briefly.
3. Strengthen the smallest relevant anchor or simplify the route.
4. Produce one corrected retry package.
5. If a compatible tool is available and authorized, rerun only that corrected
   case; otherwise leave execution explicitly not performed.
