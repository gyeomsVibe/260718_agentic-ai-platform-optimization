# MIA Custom Skills

MIA(Modular Intelligence Architect) 시리즈의 모든 사용자 제작 자료를 이곳에 둡니다.

| 경로 | 역할 |
|---|---|
| [plan-review-execute/](plan-review-execute/) | 실제 사용 가능한 MIA 공용 Skill 정본과 플랫폼 패키지 |
| [compiler-workbench/](compiler-workbench/) | 새 Skill을 설계·검증하는 Compiler 후보, 평가, 근거 |

`plan-review-execute/SKILL.md`는 실행 Skill의 정본입니다. Compiler 작업대의 후보는
정적 검증을 통과해도 자동으로 설치·배포하지 않습니다.
