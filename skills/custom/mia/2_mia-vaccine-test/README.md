# MIA 백신테스트 (mia-vaccine-test)

> 실패를 일부러 만들어(주입·변이·실사용) 정상 경로에선 안 보이는 결함을 드러내고,
> 확정된 결함마다 vibe-clinic 진단으로 항체를 남겨 재발을 막는 크로스플랫폼 Agent Skill.
> **이 폴더가 정본이다.** 3대 AI 도구 전역 설치본은 여기서 배포한다.

## 파일 소유권

| 경로 | 역할 | 직접 수정 |
|---|---|---|
| [`SKILL.md`](SKILL.md) | 세 플랫폼 공통 동작 정본 | 예 |
| [`references/vaccine-protocol.md`](references/vaccine-protocol.md) | 핵심 절차 압축 요약 (교본 없이도 동작) | 예 |
| [`agents/openai.yaml`](agents/openai.yaml) | Codex 표시명·명시 발동 정책 | 필요할 때 |

동작을 바꾸려면 `SKILL.md`만 수정하고, 전역 배포본을 다시 맞춘다.
개념 교본은 vibe-clinic 저장소 `handbook/` 06~08장.

## 발동 계약

- 문구 규칙: `MIA` + 모드 용어(붙여 씀) + `해줘`|`발동`. 예: `MIA 백신테스트 해줘`, `MIA 변이테스트 발동`.
- 모드 용어를 띄어 쓰거나(`백신 테스트`) `MIA` 접두사가 없으면 발동하지 않는다.
- 이 모드는 코드를 일부러 망가뜨리므로 오발동 비용이 크다. 애매하면 발동하지 말고 한 줄로 물어본다.
- 커밋·푸시·전역 배포·실 API 키 입력은 각각의 승인 경계를 따른다.

## 세 모드

- **A 실패주입** — 실패 상태를 심고 화면을 관찰
- **B 변이테스트** — 코드에 버그를 심어 테스트가 잡는지(killed/survived) 검사
- **C 실사용진단** — 앱을 직접 구동해 전 기능을 눌러보고 기술 보고서 작성

세 모드 모두 확정된 결함을 vibe-clinic 진단(항체)으로 승격시켜 면역 기억으로 남긴다.
