# Codex 로컬 이미지 다운로드 수정 스테이징

대상 버전: Windows Store Codex `26.715.4045.0`

## 확인된 원인

- 이미지 확대창은 `data:` URL만 Blob 다운로드로 처리한다.
- 그 외 로컬 Codex 경로는 일반 `<a download>` 링크로 넘긴다.
- Electron/WebView의 로컬 경로에서는 이 링크가 무반응이 될 수 있다.
- ZIP 미리보기 미지원은 별개이며, 파일 탭의 `열기` 및
  `폴더에서 열기` 네이티브 동작을 사용한다.

## 최소 수정

- HTTP(S)는 기존 링크 동작을 유지한다.
- `data:`는 기존 변환 로직을 유지한다.
- Blob 및 Codex 로컬 프로토콜은 `fetch -> Blob -> object URL`로 저장한다.
- 대상 번들의 파일 크기와 ASAR 전체 크기는 유지한다.
- 대상 파일의 ASAR SHA-256 무결성 값도 함께 갱신한다.

## 안전 절차

1. 설치본 `app.asar`의 SHA-256을 확인한다.
2. 설치본을 워크스페이스 백업 위치로 복사한다.
3. 별도의 스테이징 복제본에 패치를 적용한다.
4. `verify-asar.js`로 코드 마커, 크기, 파일/블록 해시를 검사한다.
5. Codex 종료 후 승인된 경우에만 설치본을 교체한다.
6. 실행 실패 시 백업본을 원래 위치로 복원한다.

Microsoft Store 업데이트가 설치되면 수정본은 덮어써질 수 있다.
