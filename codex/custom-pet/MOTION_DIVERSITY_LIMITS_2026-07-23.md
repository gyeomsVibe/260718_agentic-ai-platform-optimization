# 반려동물 모션이 "설계만큼 다양하지 않은" 근본 원인 (결론)

- 작성일: 2026-07-23
- 상태: `VERIFIED_RESULT` — 자산 검사 + 공식 이슈 2건 + Store 패키지 실측으로 교차확증
- 한 줄 결론: **자산은 이미 앱이 허용하는 최대치(9모션+16시선)까지 꽉 찼다. 병목은 앱
  런타임이며, 지금 이 환경(Store 전용 Codex)에서 모션을 더 늘릴 안전·지속 가능한 방법은 없다.**

## 1. 질문과 답

- 질문: "반려동물이 계획대로 다양한 포즈·모션을 갖게 할 수 있나?"
- 답: **지금은 없다.** 자산을 더 만든다고 해결되지 않는다. 앱을 뜯어고치는 길은 이 환경에서 막혀 있다.

## 2. 근본 원인 사슬 (증거 기반)

```
자산은 이미 리치(9모션+16시선, 실측 확인)
  → 그런데 바닐라 Codex 앱이 모션 종류·프레임 수·트리거를 하드코딩 (pet.json으로 제어 불가)
  → 유일한 해제책은 app.asar 패치(hlky 모드)
  → 그러나 Codex 데스크톱은 Microsoft Store(MSIX) 패키지 = OS 무결성 강제
  → 파일 변조는 차단·자동복구되고, 패치해도 서명 불일치로 기동 실패 위험
  → 비-Store/포터블 배포본은 존재하지 않음(요청 이슈만 열려 있음)
  → 따라서 안전·지속 가능한 해결 경로 없음
```

## 3. 증거 표

| # | 사실 | 출처 |
|---|---|---|
| 1 | 설치 자산은 9모션 전부 실제 프레임 + 16방향 시선. idle엔 앱이 안 트는 여분 프레임까지 있음 | 로컬 `qa/runtime-self-test/motion-self-test.json` |
| 2 | 설치 상태 정상: `gyeom-v2` 단독, pet.json v2, 스프라이트 해시 일치, config `selected-avatar-id=custom:gyeom-v2` | `~/.codex/pets/` 실측 |
| 3 | 앱이 프레임 수·타이밍·시퀀스·트리거를 하드코딩, pet.json은 모션 정의 미지원 | [openai/codex#20863](https://github.com/openai/codex/issues/20863) (open, 공식 대응 없음) |
| 4 | 표준 Windows 설치본(codex-setup.exe/.msi) 없음 — 데스크톱은 Store 전용 | [openai/codex#13993](https://github.com/openai/codex/issues/13993) (open) |
| 5 | Codex 데스크톱 = `SignatureKind: Store` MSIX 패키지 (OS 무결성 강제) | `Get-AppxPackage OpenAI.Codex` 실측 |

## 4. 검토한 모든 우회로와 기각 사유 (/CRITIC)

| 우회로 | 왜 안 되나 |
|---|---|
| **hlky codex_app_pet_mod** (app.asar + Codex.exe 패치) | Store MSIX OS 무결성이 변조를 차단·자동복구. Electron asar 해시를 고쳐도 **MSIX 서명 불일치**로 기동 실패 위험. 게다가 모드는 26.429 타깃(현재 26.715 미검증), ⭐0·PoC |
| **업데이트 감지 후 자동 재패치/롤백 스크립트** (사용자 제안) | 발상은 건전하나 **OS가 능동적으로 되돌리는 변조를 매일 반복 강행**하는 구조. 우리 일일 자동업데이터와 상충, 매 사이클 기동파손 룰렛, 버전 표류로 콘텐츠 매칭 실패. 자물쇠를 매일 부수는 로봇 |
| **MSIX 재서명 후 사이드로드** | 개발자 모드 + 자가서명 + Store본 제거 + 사이드로드. 매 업데이트마다 재수행, 샌드박스·인증이 패키지 정체성에 묶여 깨질 위험. 반려동물 하나 위해 감당 불가 |
| **비-Store/포터블 Codex 패치** | 그런 배포본이 존재하지 않음(#13993) |
| **자산 추가 제작** | 이미 앱 상한(9종)을 꽉 채움. 더 만들어도 앱이 안 틈 |

## 5. 유일하게 지속 가능한 길 + 위안

1. **공식 대응을 기다린다 — [openai/codex#20863](https://github.com/openai/codex/issues/20863) 워치.**
   pet.json에 `animation`(행·duration·프레임수·시퀀스) 필드가 들어오면 **패치 없이** Store 무결성과
   안 싸우고 모션을 제어할 수 있다. 이것이 유일한 깨끗한 경로다.
2. **당신의 리치한 자산은 낭비가 아니다.** [backnotprop/codex-pets-react](https://github.com/backnotprop/codex-pets-react)
   같은 **독립 React 뷰어**로 9모션+16시선을 **전부** 렌더해 개인 웹/위젯에서 온전히 감상·전시할 수 있다.
   (Codex 앱 펫 자체는 아니지만, 설계한 모든 동작을 실제로 볼 수 있는 유일한 방법.)

## 6. 판정과 재검토 조건

- **판정: No-Go (현 시점, 이 환경).** 안전·지속 가능한 방법 없음. 무리한 앱 패치는 하지 않는다.
- **재검토 트리거**: ① #20863이 pet.json animation 필드를 릴리스, 또는 ② OpenAI가 비-Store 데스크톱
  배포본(#13993)을 제공. 둘 중 하나가 충족되면 그때 다시 실행 검토한다.
- **하지 말 것**: Store MSIX in-place 패치, 그를 자동화하는 스크립트. (OS 무결성과 싸워 이길 수 없고,
  이번 세션에서 확립한 "위험한 앱 바이너리 패치 회피" 원칙과도 어긋난다.)
