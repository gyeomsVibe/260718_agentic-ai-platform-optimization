# Gyeom Companion MVP 상품 패키지

## 고객이 받는 경험

Gyeom Companion은 Codex 화면 위에서 살아 있는 캐릭터를 보여 주는 Windows
보조 오버레이입니다. Codex 앱 내부의 Pet 재생 규칙을 바꾸지 않으므로, 앱 업데이트나
서명된 파일을 수정하지 않습니다.

## 세 가지 상품 단위

| 상품 | 제공물 | 약속하지 않는 것 |
| --- | --- | --- |
| Starter Native Pet | Codex 선택기용 호환 Pet, 설치 안내 | Codex가 모든 행동을 자동 재생하는 것 |
| Companion | 항상 위 오버레이, 생활 모션 4종, 9개 업무·반응 상태, 상태 전환 명령 | Codex 작업 내용을 자동으로 읽는 것 |
| Studio Custom | 고객 캐릭터 계약, 맞춤 생활·업무 행동, 성격 설정, 설치·검수 자료 | 타인 초상·상표 캐릭터의 무단 상업 사용 |

## Companion MVP 포함 기능

- 호흡·눈깜빡임 기본 루프
- 두리번거리기, 기지개, 하품의 일회성 생활 행동
- 인사와 검토를 포함한 자동 성격 행동
- `running`, `waiting`, `review`, `failed` 등 9개 수동 상태
- 우클릭 메뉴, 왼쪽 드래그 이동, `Esc` 종료
- 상태 파일 기반의 로컬 자동화 경계
- 60초 실화면 관찰 기록과 A/B 접촉표

## 판매 전 통과 기준

1. 60초 동안 여섯 종류 이상의 상태가 실제 화면에 나타난다.
2. 성격 행동과 외부 상태 명령이 모두 기록된다.
3. 창 이동, 우클릭, 종료가 정상 동작한다.
4. 고객 캐릭터의 얼굴·의상·비율이 전체 행동에서 유지된다.
5. Native Pet과 Companion의 기능 차이를 상품 설명에 분명히 적는다.

## 초보 고객용 시작

1. `Start-GyeomPetOverlay.cmd`를 더블클릭한다.
2. 화면 오른쪽 아래의 캐릭터를 왼쪽 마우스로 원하는 곳으로 옮긴다.
3. 오른쪽 클릭으로 행동을 고르거나 성격 루프를 켠다.
4. 끄려면 `Esc`를 누르거나 오른쪽 클릭 후 `오버레이 닫기`를 선택한다.

자세한 상태 전환 명령과 검증 방법은 [README.md](README.md)를 따른다.
