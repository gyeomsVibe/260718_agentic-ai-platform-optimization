# Gyeom Native Pet A/B 시험

## 목적

기존 `gyeom-v2` 설치본은 보존한 채, 대기 행의 눈깜빡임과 미세한 자세 변화가
명확한 `gyeom-v2-ab` 후보를 만들어 Codex 화면에서 실제 재생 여부를 비교한다.

## 고정 조건

- 설치 ID는 `gyeom-v2-ab`이며 기존 `gyeom-v2`를 덮어쓰지 않는다.
- 스프라이트는 Codex Pet v2의 `8×11`, `1536×2288` 규격을 유지한다.
- 행 1~10은 기준 후보와 동일하게 보존한다.
- 행 0만 명확한 idle loop로 교체한다.

## 판정 기준

- 60초 대기에서 눈깜빡임 또는 고개·상체 변화가 세 번 이상 분명히 보인다.
- 작업 중 상태 전환이 두 종류 이상 관찰되면 Native Pet 유지 가능성을 재검토한다.
- Codex가 새 idle 행을 재생하지 않거나 변화가 보이지 않으면 Companion을 주력 경로로 전환한다.

## 중간 결과

- 기존 `gyeom-v2` 설치본의 해시는 기준 후보와 일치했다.
- 생성한 7프레임 idle strip은 눈깜빡임이 명확했고, `stable-slots` 추출과
  구조 검사를 통과했다. 다만 기존 캐릭터보다 얼굴 비율이 커 보여 시각 정체성
  검토가 추가로 필요하다.
- 제공된 Pet 조립 도구는 기존 8×11 시트의 9·10행 시선 프레임 조립만 지원한다.
  0행 idle을 교체해 다시 패키징하는 지원 경로는 없다.

## 상태

`BLOCKED_ON_VALID_PACKAGING` — 8×9을 설치본으로 쓰는 것은 v2 규격 위반이며,
0행만 별도 코드로 합성하는 것은 검증된 제작 절차를 벗어난다.

## 다음 선택지

1. 동일 캐릭터 계약으로 11행 전체를 새로 생성해 `gyeom-v2-ab` v2 패키지를
   만들고, 실제 Codex 화면에서 A/B 검증한다.
2. Native Pet은 현재 승인본을 유지하고, 이미 있는 Companion Overlay에서
   눈깜빡임·하품·대기 성격 루프를 완전 제어하는 상품 경로를 먼저 검증한다.

## 결정

`GO — Companion 주력 상품`

- 주력 가치: 사용자가 대기 중에도 살아 있다고 느끼는 눈깜빡임, 하품, 시선,
  자세 변화와 상황별 반응을 Companion이 책임진다.
- Native Pet: Codex 선택기에 보이는 호환 설치 옵션으로 유지한다. 앱이 어떤
  상태·프레임을 재생할지는 제품 약속에 포함하지 않는다.
- 다음 구현: Companion Overlay에 예측 가능한 idle 성격 루프와 상태 전환
  UX를 추가하고, 2분 관찰에서 다섯 번 이상의 명확한 변화를 검증한다.
