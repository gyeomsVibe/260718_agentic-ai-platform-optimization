# Gyeom v2 시선 교정 QA 결과

## 결과

- 최종 시트 규격: 1536×2288, 8열×11행, RGBA WebP
- Sprite version: 2
- 표준 동작 0–8행: 기존 승인 자산 유지
- 시선 동작 9행: 000–157.5도 8프레임
- 시선 동작 10행: 180–337.5도 8프레임
- 사용 프레임 수: 총 75개

## 통과 항목

- 엄격 시트 구조 검사 통과
- 투명 RGB 찌꺼기 0픽셀
- 프레임 경계 침범 0건
- 빈 프레임 및 크기 이상치 0건
- 전체 11행 GIF 시뮬레이션 생성 완료
- 시선 16방향 의미와 순서 시각 검사 완료
- 8행 4번은 동일 행 기준 높이·비율로 교정 유지

## 검토 경고

- 시선 연속성 검사에서 `157.5→180`, `337.5→000` 전환이 인접 프레임보다 큰 로컬 이상치로 표시됐다.
- 두 전환 모두 행 경계 또는 순환 경계이며, 확대 시트에서 방향 반전·크기 변화·바닥선 이탈은 발견되지 않았다.
- 자동 결과는 `ok: true`, `reviewRequired: true`이다.

## 설치 조건

- `qa/contact-sheet.png`와 `qa/direction-qa.png`에 대한 사용자 최종 시각 승인을 받은 뒤 설치한다.
- 설치 후 Codex 앱을 완전히 재시작하고 Pet 선택 화면을 새로고침한다.
- 실제 런타임에서 표준 9개 동작 호출 여부는 별도 상태 전이 테스트로 확인한다.
