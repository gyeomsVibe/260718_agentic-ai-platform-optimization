# 이전 Codex Pet Mod 자료

> 2026-07-18 전후의 제작 입력, 실행 계획, Advanced Pet Mod 초안을 보존한 역사 자료입니다.
> 현재 설치 매뉴얼이나 실행 가능한 완성 패키지가 아닙니다.

## 현재 정본

현재 제작·검증 절차는 상위 [커스텀 Pet 매뉴얼](../../README.md)을 따릅니다. 이 폴더의
문서와 이미지는 당시 판단을 재현하거나 개선 과정을 비교할 때만 사용합니다.

## 보존한 자료

- [MIA 실행 계획](<01.MIA 효율적, 최적화 작업계획-실행 계획 작성.md>)
- [Advanced Pet Mod 초안](<04. Codex App Pet Mod.md>)
- 당시 비교·교정에 사용한 PNG 이미지 4개

Advanced Pet Mod 초안이 가리키던 동영상, 예제 Pet, TypeScript 소스, 추가 문서는 이
저장소에 들어오지 않았습니다. 존재하지 않는 대상을 실행 가능한 링크로 오해하지 않도록
파일 경로 표기로 바꿨습니다.

## 사용 경계

- 이 폴더를 현재 Codex 앱에 직접 설치하지 않습니다.
- 앱 패치와 전역 Pet 설치는 현재 매뉴얼의 백업·검증 절차를 따릅니다.
- 이미지의 공개 적합성과 권리는 별도로 확인합니다. 확인 전에는 새 배포물에 재사용하지
  않습니다.
