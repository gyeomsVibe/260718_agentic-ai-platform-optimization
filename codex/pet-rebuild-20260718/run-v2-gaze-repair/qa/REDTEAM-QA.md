## GIF 검은 테두리 원인

GIF는 1비트 투명도만 지원해 반투명 안티앨리어싱을 보존하지 못한다. 기존 GIF의
투명 팔레트 색이 검정색이며 부분 알파가 0이어서, 일부 뷰어에서 검정 매트 또는
테두리처럼 보인다. 이는 최종 Pet 원본 WebP의 결함이 아니다.

최종 판정은 다음 자료로 수행한다.

- `previews-hq/apng`: 원본 RGBA와 완전 동일한 무손실 미리보기
- `previews-hq/webp`: 보이는 픽셀과 알파가 동일한 애니메이션 WebP
- `alpha-background-comparison.png`: 서로 다른 3개 배경의 가장자리 비교

animated WebP 인코더가 알파 0인 완전 투명 픽셀의 숨은 RGB를 채울 수 있으나,
알파와 모든 보이는 픽셀은 원본과 일치한다. 렌더링 결과에는 영향을 주지 않는다.

## 남은 단계

사용자가 고품질 미리보기와 배경 비교표를 승인한 뒤에만 설치한다. 설치 후에는
Codex 앱에서 실제 상태 전환과 9개 표준 모션 호출을 별도로 런타임 검증한다.
