# Gyeom 시선 동작 규격

## 고정 요소

- 캐릭터 외형, 얼굴 비율, 머리 크기, 신체 비율을 기준 이미지와 동일하게 유지한다.
- 검정 소매·밝은 회색 몸판의 래글런 상의, 진청색 일자 청바지, 검정 하이탑 운동화를 유지한다.
- 두 발의 위치와 바닥 기준선, 몸통의 정면 방향, 전체 캐릭터 크기를 모든 프레임에서 고정한다.
- 소품, 문자, 그림자, 발광 효과, 외곽 색 테두리를 추가하지 않는다.

## 동작 원리

- 시선은 눈동자가 먼저 이동하고, 눈꺼풀과 눈썹이 방향을 보조한다.
- 머리와 목은 눈을 따라 소폭만 기울이며, 어깨와 상체는 거의 정면을 유지한다.
- 좌우 시선에서도 옆모습이나 뒷모습으로 회전하지 않는다.
- 상·하 시선에서도 캐릭터 전체를 회전하거나 찌그러뜨리지 않는다.

## 4개 기준 방향

- `000`: 위를 봄. 눈동자는 위, 턱은 조금 들고 머리는 뒤로 아주 약하게 기울인다.
- `090`: 화면 오른쪽을 봄. 눈동자는 오른쪽, 머리는 오른쪽으로 소폭만 돌린다.
- `180`: 아래를 봄. 눈동자는 아래, 턱은 조금 내린다.
- `270`: 화면 왼쪽을 봄. 눈동자는 왼쪽, 머리는 왼쪽으로 소폭만 돌린다.

## 행 구성

- 9행: `000`, `022.5`, `045`, `067.5`, `090`, `112.5`, `135`, `157.5`
- 10행: `180`, `202.5`, `225`, `247.5`, `270`, `292.5`, `315`, `337.5`
- 각 행은 개별 셀 조합이 아닌 하나의 일관된 8프레임 스트립으로 생성한다.
- 인접 프레임은 눈동자와 머리 각도가 부드럽게 이어져야 한다.

## 합격 기준

- 모든 방향이 라벨 없이도 구분된다.
- 16프레임 전체에서 얼굴·의상·비율·크기·바닥선이 일관된다.
- 턴어라운드처럼 등이나 완전한 측면이 노출되지 않는다.
- 배경 제거 후 불투명 마젠타, 붉은색·초록색 프린지, 투명 RGB 찌꺼기가 없다.
