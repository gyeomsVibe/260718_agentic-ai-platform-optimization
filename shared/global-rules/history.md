# 글로벌 룰 변경 이력

## v5.6.0

- 사용자 지시(2026-09-20): 무승인 진행을 막던 승인 목록을 화이트리스트로 좁혔다. 사람만 누를 것은 삭제·원격 push·배포·공개 게시·스토어 제출·지출·계정/자격증명/권한/시스템 설정 변경뿐이다.
- 덮어쓰기와 프로젝트 의존성 설치는 `.work/backup_<날짜>/` 선백업을 조건으로 무승인 진행한다.

## v5.5.0

- U15 S1~S4 구현에서 값이 증명된 두 항목을 검증 절에 고정했다.
- 단계마다 통과할 관문을 먼저 선언하고 끝난 뒤 그 관문으로 판정한다. 관문 없는 단계는 완료가 아니라 미측정이다.
- 동시성·원자성은 실제 병렬 테스트로 증명한다. Windows에서 다중 writer의 `O_APPEND`가 줄을 유실하는 것을 실측해 파일 잠금으로 교정했다.

## v5.4.0

- 기사 2건(GeekNews 33735 "Do You Still Read the Code?", 33727 "코딩 에이전트에 프로젝트 위임") 전수 분석에서 실제 사고·비용과 직결된 항목만 골라 반영했다. 근거 정리는 `260916_agentic-ai-env-diet/docs/claude-assist/70_global-rules-v54-proposal-from-two-articles_2026-09-20.md`.
- 소유권: 미추적 디렉터리 이동·삭제 금지(막히면 stash·워크트리), 빈 결과를 "같음"으로 읽지 않기.
- 검증: 값·설계 선택의 근거를 옆에 기록(의도 부채 방지), 테스트 통과만 보지 말고 벽시계·토큰 3배 악화를 실패로 보고.
- 범위: 단계마다 필요한 맥락만 전달하고 결정은 계획·카드로 이어가기, 산출물을 폐기 가능/유지보수로 구분.
- 어댑터: Codex는 계획·게이트·판정 소유와 프롬프트 고정 접두부 유지, Antigravity는 staging 한정 쓰기·인수 테스트 불변·무변경 종료는 실패·QUIET_LOCK 준수.
- 미반영 1건: 승인 목록을 화이트리스트로 좁히는 개정은 Claude 측 플랫폼 가드가 막아 이번 판에 들어가지 못했다. 문구는 메모 70 §3에 보존한다.

## v5.3.0

- 사용자 지시(2026-09-20): **추천** 항목 및 관련 문구를 전면 영구 삭제하고 출력은 오직 **결과**(1~3줄)로 단일화했다.
- 사용자 부재/외출 상황에서도 도구 간 릴레이·파일을 통해 3대 도구가 상호 직접 소통하여 끝까지 자율 완결하는 절대적 직접 수행 원칙을 영구 고정했다.
- 기사 2종 인사이트(도메인 이해 유지, 코드 나열 배제, 승인 관문 멈춤 원천 차단)를 반영했다.

## v5.1.0

- 사용자 지시(2026-09-20): **추천**은 승인 관문이 아니라 이어서 수행할 일을 적는 칸임을 명시했다. 회신을 기다리지 않고 같은 차례에 실행한다.

## v5.0.0

- 라이브 전역 규칙(사용자 지시 2026-09-19, 한국어 경량판)을 정본에 역반영했다. 출력은 결과·추천 두 부분으로 고정하고 긴 설명을 금지했다.
- 선구현 후교정과 덮어쓰기 전 백업 규칙을 검증 항목에 추가했다.
- 워크스페이스 위생(프로젝트당 폴더 하나, `.work/` 격리)을 범위 항목에 추가했다.
- v4.2.0의 `[WP:<작업ID>:<순번>]` 통합 작업계획 절차는 한 줄 규칙으로 축약했다. 항상 로드되는 규칙을 짧게 유지하기 위함이다.
