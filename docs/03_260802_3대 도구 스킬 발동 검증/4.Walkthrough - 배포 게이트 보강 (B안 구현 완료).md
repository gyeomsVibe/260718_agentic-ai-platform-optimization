## 1. 구현된 보강 사항 (3대 구조적 통제)

### 1) [F3] `.gitattributes` BOM 강제 규칙 편입
- **목적**: 에디터나 도구가 `.ps1` 파일의 BOM을 제거하더라도 Git checkout 시 `UTF-8-BOM`을 자동 부여하도록 설정.
- **수정 위치**: [.gitattributes](file:///d:/D_Workspace_NB/-agentic-ai-workspace/260718_agentic-ai-platform-optimization/.gitattributes)
- **추가 규칙**:
  ```gitattributes
  # PowerShell 5.1은 BOM 없는 UTF-8을 시스템 코드페이지(CP949)로 읽어 한국어가 깨진다.
  # working-tree-encoding=UTF-8-BOM으로 checkout 시 BOM을 자동 부여한다.
  *.ps1 text eol=crlf working-tree-encoding=UTF-8-BOM
  ```

### 2) [F1] `validate-skill-manifests.py` 생성본 검증 및 한국어 손상 진단 추가
- **목적**: 정본 뿐만 아니라 파이프라인에서 생성되는 어댑터/플러그인 파일(`CLAUDE-SKILL.md`, `plugin/skills/.../SKILL.md`)의 frontmatter 파싱 및 한국어 모지바케(`KOREAN_INTEGRITY_PHRASES`) 검증을 자동 수행.
- **수정 위치**: [validate-skill-manifests.py](file:///d:/D_Workspace_NB/-agentic-ai-workspace/260718_agentic-ai-platform-optimization/skills/custom/mia/scripts/validate-skill-manifests.py)
- **검사 대상**: 정본 스킬 3개 + 생성본 2개 총 5개 매니페스트.

### 3) [F5] `package.json` CI 통합 (`npm run skills:check`)
- **목적**: `npm run check` 실행 시 스킬 배포 카탈로그의 15개 타깃 정합성 및 매니페스트 검사가 자동으로 수행되도록 편입.
- **수정 위치**: [package.json](file:///d:/D_Workspace_NB/-agentic-ai-workspace/260718_agentic-ai-platform-optimization/package.json)
- **추가 스크립트**:
  ```json
  "skills:check": "powershell -ExecutionPolicy Bypass -File skills/custom/mia/scripts/sync-mia-catalog.ps1 -Mode Check",
  "check": "npm run typecheck && npm run lint && npm run handoff:test && npm run handoff:check && npm run skills:check"
  ```
